KEY DATA FLOWS:
- Authentication: SQLite (krishisetu_auth.db) - users, personas, roles
- Crop Recommendations: Crop database (13 crops with agro parameters)
- Marketplace: JSON file (marketplace_data.json) - listings + buyer demands
- Weather: Open-Meteo API + cached fallback data
- Chat History: SQLite (persistent across sessions)
- all agro decisions use multilingual TRANSLATIONS (en/hi/mr)
