# krishisetu

## Farmer policies

The **Policies** tab provides simple guidance on Indian and Maharashtra farmer
schemes, crop insurance, subsidies, MSP and selling, farm credit, and import/export
rules. Government links are provided for current eligibility, amounts, deadlines,
and commodity-specific rules, which can change. A crop cost/profit calculator
estimates results only from farmer-entered figures; it is not a guaranteed return.

Run with `streamlit run app.py`. No additional API key is needed for Policies.
